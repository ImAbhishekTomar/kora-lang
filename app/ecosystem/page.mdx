# Ecosystem

Kora is a language and a small set of tools around it. The goal is for setup to
feel like one smooth experience.

## VS Code

The published extension is available today:

- `.ko` files are recognized as Kora.
- Syntax gets colorized.
- **Kora: Run Current File** and **Kora: Test Current File** run commands from the editor.
- IntelliSense includes diagnostics, completion, hover, symbols, and go-to-definition.
- Press **F5** to debug: breakpoints, step over / into / out, the call stack,
  and a variables pane. No `launch.json` needed to start.

[Install Kora Language from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kora-lang.kora-lang), then install the CLI using [Homebrew, npm, a release archive, or source](/installation).

## The one-install direction

The extension and CLI work together as the Kora development environment:

```text
Kora extension
├── compiler + CLI (installed separately)
├── IntelliSense
├── syntax colors + themes
├── .ko file icons
├── debugger (breakpoints, stepping, variables)
└── run, replay, and project tools
```

Open a Kora project, install the extension and CLI, and start writing without
assembling separate syntax and language-server tools.

## Runtime pieces

The repository is organized into focused Rust crates:

| Piece | What it does |
| --- | --- |
| `kora-syntax` | Lexer, parser, and AST |
| `kora-types` | Type checking and data labels |
| `kora-runtime` | Interpreter, cassettes, and execution |
| `kora-models` | OpenAI and Ollama model clients |
| `kora-lsp` | Language server foundation |
| `kora-dap` | Debug adapter: breakpoints, stepping, variables |
| `kora-cli` | The `kora` command |

You can browse the full [repository](https://github.com/ImAbhishekTomar/kora-lang) when you want to go deeper.
