# Start here

Kora is still pre-alpha, but you can install the current release directly.

## 1. Install Kora

Choose one:

```bash
brew tap ImAbhishekTomar/tap
brew install imabhishektomar/tap/kora
```

```bash
npm install -g @abhishektomar/kora-cli
```

Or follow the complete [Installation guide](/installation) for release
archives and source builds.

## 2. Check the CLI

```bash
kora --version
kora check examples/00_basics.ko
```

## 3. Run a tiny program

```bash
kora run examples/00_basics.ko
```

If you want to build from source instead, install Rust and Cargo:

```bash
git clone https://github.com/ImAbhishekTomar/kora-lang.git
cd kora-lang
cargo build --release --locked
```

Check that the CLI is ready:

```bash
./target/release/kora --version
./target/release/kora run examples/00_basics.ko
```

## 4. Open it in VS Code

Install [Kora Language from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kora-lang.kora-lang).

Open a `.ko` file. You get syntax colors, file icons, diagnostics, completion,
hover, go-to-definition, and run/test commands. Set `kora.serverPath` if the
CLI is not on your `PATH`.
