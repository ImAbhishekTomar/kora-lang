# Kora `0.0.1`

Published 27 August 2026. [View the release and downloads](https://github.com/ImAbhishekTomar/kora-lang/releases/tag/v0.0.1).

`0.0.1` is Kora's first public pre-alpha release. It establishes the language
foundation and the first usable developer workflow.

## Changes

- Python-like Kora syntax, static type checking, the interpreter, and the
  `kora` command-line tool.
- Initial VS Code syntax highlighting, file icon, and run support.
- Runnable examples and automated checks across the supported platforms.

## Breaking changes

None. This is the initial release, so there is no earlier Kora version to
migrate from.

## Migration and upgrade

Install `0.0.1` only when you need to reproduce the original release. New
projects should use the latest release instead. If you are moving from
`0.0.1`, continue with the [`0.0.2` migration guide](/releases/0.0.2).

```bash
npm install -g @abhishektomar/kora-cli@0.0.1
kora --version
```

## Compatibility

Kora `0.0.1` is pre-alpha. Its language surface and tooling were deliberately
allowed to evolve in later pre-alpha releases.
