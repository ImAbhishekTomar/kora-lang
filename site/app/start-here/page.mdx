# Getting started

This path gets a Kora program running in three minutes. It uses the
deterministic core, so no API key, model, or extra dependency is required.

## 1. Install Kora

Choose one:

```bash
brew tap ImAbhishekTomar/tap
brew install imabhishektomar/tap/kora
```

```bash
npm install -g @abhishektomar/kora-cli
```

Or follow the complete [Installation guide](/installation) for release
archives and source builds.

See [Install Kora](/installation) for release archives, source builds, and the
VS Code extension.

## 2. Write a small program

Create `hello.ko`:

```kora
type User:
    name: str

def greet(user: User) -> str:
    return f"Hello, {user.name}!"

def main():
    ada = User("Ada")
    print(greet(ada))
```

This program uses only a type, a function, a value, and `print`. It does not
call a model or read a file.

## 3. Check, then run

```bash
kora --version
kora check hello.ko
kora run hello.ko
```

Expected output:

```text
Hello, Ada!
```

## Try a real example

The repository includes a larger program with records, loops, conditions, and
f-strings:

```bash
kora check examples/00_basics.ko
kora run examples/00_basics.ko
```

## Use VS Code

Install [Kora Language from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kora-lang.kora-lang).

Open a `.ko` file. You get syntax colors, file icons, diagnostics, completion,
hover, go-to-definition, and run/test commands. Set `kora.serverPath` if the
CLI is not on your `PATH`.
