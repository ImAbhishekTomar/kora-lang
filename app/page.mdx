## A tiny taste

```kora
type Mood:
    label: str
    kind: str

def main():
    mood: Mood = analyze("I finally shipped it!", "describe the mood")
    match mood:
        case Ok(m):
            print(f"{m.label} ({m.kind})")
        case Uncertain(reason):
            print(f"Try again: {reason}")
```

That is the idea: ordinary-looking code, with the model boundary made explicit.
